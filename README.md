# Indoor Temperature and Office Work Performance in a Temperate Climate

This repository contains the anonymized data, analysis code, and manuscript
source needed to reproduce the results in:

Kramer, T., & Schiavon, S. (2026). Indoor temperature and office work performance in a temperate climate. Buildings and Cities, 7(1), 1162–1180. https://doi.org/10.5334/bc.876


It is a cleaned, public-facing companion to the authors' private working
repository: it excludes raw data, reviewer/editor correspondence, and
internal lab notes, and includes everything else needed to run the analysis
end to end.

## Study overview

Participants completed cognitive assessments (a Cognitive Ability Test and
the PEBL neuropsychological battery) and thermal comfort surveys under four
temperature conditions (21°C, 23°C, 25°C, 27°C) in a controlled
environmental chamber, within a within-subjects design. Physiological
measurements (heart rate variability, skin temperature) and environmental
conditions were recorded throughout each session.

## Setup

This project uses [`renv`](https://rstudio.github.io/renv/) for R package
management.

```r
install.packages("renv")
renv::restore()
```

Rendering the manuscript additionally requires [Quarto](https://quarto.org).

## Running the analysis

```r
source("code/analysis.R")
```

This reads the data in `data/`, runs all statistical tests, and regenerates
the figures in `manuscript/figs/` (two figures — `tsk_hr.png` and the minute-
by-minute skin-temperature trace it's based on — cannot be regenerated from
the public data tier and ship pre-rendered; see `data/README.md` for why).

## Rendering the manuscript

```bash
quarto render manuscript/manuscript.qmd
```

This sources `code/analysis.R` directly in its first chunk, so all analysis
objects are available for inline reporting in the manuscript text.
