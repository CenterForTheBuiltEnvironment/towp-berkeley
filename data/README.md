# Data

This directory contains the anonymized, processed dataset needed to reproduce
the statistical analysis and figures in the manuscript. No raw data files are
included — identifiable raw data (free-text survey fields, exact timestamps,
alphanumeric subject codes, and quasi-identifying demographic fields such as
birth country/state) remain in the authors' private repository and are not
shared.

## Anonymization

- `subject_id` has been stripped of its original alphanumeric prefix, leaving
  only a numeric code (e.g. the original `ae057` becomes `057`). This mapping
  is consistent across all files below.
- All absolute timestamps have been removed or converted to relative
  measures (e.g. `time_from_start_min` in `hrv.csv`).
- Only subjects who completed all four sessions are included (`subjects.csv`
  and all files derived from it).
- Free-text fields and quasi-identifying demographic fields (birth
  country/state, current living location, exact medication/meal text, etc.)
  are not included anywhere in this export.

## Files

| File | Rows | Description |
|---|---|---|
| `subjects.csv` | 75 | Demographics and health routines, one row per participant |
| `env_sessions.csv` | 100 | Mean chamber air temperature, RH, and CO2 per session |
| `cat.csv` | 309 | Cognitive Ability Test (CAT) scores, one row per participant per session |
| `hrv.csv` | ~46k | Cleaned, 1-minute-windowed heart rate / RMSSD measurements |
| `survey_long.csv` | ~8.6k | Thermal comfort survey responses (long format: one row per question) |
| `pebl_long.csv` | ~21k | PEBL cognitive battery results (long format: one row per metric) |
| `pebl_domain_summary.csv` | 18 | Precomputed domain-level performance-change summary (depends on objects generated mid-pipeline; shipped directly so it doesn't need to be regenerated) |
| `tsk.csv` | 326,898 | Cleaned, per-minute skin-temperature measurements, relative to session start |

`code/src/data.R` reads these files and reconstructs the wide-format tibbles
(`subjects`, `cat`, `hrv`, `survey`, `pebl`, `env_sessions`, `tsk`) used
throughout `code/src/func.R`, `code/src/stat.R`, and `code/analysis.R`.

## Known limitations of this data tier

One part of the original analysis pipeline operates on data that sits at a
finer resolution than what's published here, for privacy/scope reasons:

1. **Environmental readings.** `env_sessions.csv` holds one row per
   *session* (already averaged from the original per-reading sensor log,
   which is not published). The environmental-conditions table generated by
   `code/analysis.R` (`env_summary`) is therefore accurate for the mean air
   temperature/RH/CO2 per condition, but its reported standard deviation
   reflects *between-session* variability rather than the finer
   *within-session, per-reading* variability reported in the manuscript's
   table. The difference is small (manuscript: SD ≈ 0.2-0.3°C for air
   temperature; reconstructed: SD ≈ 0.1°C) and does not affect any
   statistical test — only that one descriptive table's SD column.

2. **RMSSD (HRV) mixed-effects model.** `hrv.csv`'s `time_from_start_min`
   column was built by excluding any readings keyed before a session's
   official start time, a filter that (unlike in the original pipeline) is
   also applied before the RMSSD model is fit. This excludes a small number
   of boundary readings, so `code/analysis.R`'s unadjusted RMSSD model
   reports F(3, 224.2) = 22.06, p < .001, versus the manuscript's F(3, 222.3)
   = 21.16, p < .001 — the conclusion (p < .001) is unchanged, but the exact
   F/df differ slightly. All other reported statistics in this repository
   (the CAT repeated-measures ANOVA, PEBL domain equivalence tests, LMM
   subgroup analyses, demographics, HR/RMSSD descriptive means, and the
   skin-temperature summary) are bit-for-bit identical to the manuscript.
